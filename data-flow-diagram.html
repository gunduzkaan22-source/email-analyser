End-to-End Data Flow
Client Invoice
Origin · Client System
Formats: PDF, scanned image, email attachment
Location: Client's own system or email client
At rest: No MailLens storage at this stage
PII present: Supplier names, amounts, addresses
TLS 1.2+
Upload / Paste
Invoice text submitted by user
MailLens App
maillens.uk · Supabase
Receives: Invoice text (user-submitted)
Auth: Supabase magic-link, Row Level Security
Stores: Analysis result only — auto-deleted after 90 days
Database: EU-hosted (Ireland), encrypted at rest
TLS 1.2+
API Request
Invoice text only · no metadata
Anthropic Claude API
api.anthropic.com
Processes: Invoice text → structured extraction
Extracts: Supplier · Amount · VAT · Due Date
Retains: Nothing. Zero data retained after response
Training: API data is not used to train models
TLS 1.2+
Extraction Result
Structured fields returned
Human Approval
Mandatory Gate
Reviewer sees: Extracted fields + original invoice
Action: Approve or reject each transaction individually
Audit log: Timestamp + reviewer ID recorded
Guarantee: No automated financial posting — ever
TLS 1.2+
Approved Only
No raw invoice text transmitted
QuickBooks
Intuit Platform
Receives: Approved bill record only
Data posted: Supplier · Amount · VAT code · Due date
Raw invoice: Never transmitted to QuickBooks
Access: OAuth 2.0, scoped to bill creation only
Encryption & Access Controls
All data transmitted via TLS 1.2+ encryption at every stage of the pipeline without exception
Session cookies set Secure, HttpOnly, SameSite=Strict — no cross-site session leakage
Database access protected by Row Level Security — your account can only access your firm's records
Content Security Policy enforced — no external scripts, no third-party font CDNs
Data Retention & Processor Terms
Anthropic does not retain API data for model training — confirmed in commercial usage terms
Invoice analysis data automatically deleted after 90 days; manual deletion available immediately via in-app controls
Anthropic DPA: Incorporated into Commercial Terms of Service — available at anthropic.com/legal
Supabase DPA in place; database hosted EU (Ireland) with SOC 2 Type II certification
Regulatory & User Rights
ICO Registration: C1928867 (pending confirmation) — registered data controller under UK GDPR
GDPR rights implemented in-product: Access · Deletion · Export · Correction (Articles 15–20, UK GDPR)
Human approval required before any transaction reaches QuickBooks — no fully automated financial posting
Privacy Notice published at maillens.uk/privacy — plain-language, no legal jargon
